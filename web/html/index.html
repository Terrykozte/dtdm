MyMiniCloud – Home

Dịch vụ trong hệ thống

Các liên kết bên dưới được tạo tự động theo địa chỉ máy chủ hiện tại (localhost), nên hoạt động cả trên máy cá nhân lẫn trên AWS EC2.

🌐 Web Frontend

Nginx phục vụ trang web tĩnh và blog cá nhân.

http://HOST:8080/

⚙️ Application Backend

Ứng dụng Flask cung cấp REST API cho hệ thống.

http://HOST/api/hello http://HOST:8085/hello (truy cập trực tiếp)

🎓 Student API & DB API

API danh sách sinh viên (JSON) và API đọc dữ liệu từ MariaDB.

http://HOST/api/student http://HOST/student/ http://HOST/api/students-db

🗄️ Database (MariaDB)

Cơ sở dữ liệu quan hệ lưu thông tin sinh viên.

port 3306 (nội bộ)

🔐 Authentication (Keycloak)

Quản lý định danh, đăng nhập và phân quyền người dùng.

http://HOST:8081/auth/ Tài khoản: admin/admin

🪣 Object Storage (MinIO)

Lưu trữ đối tượng tương thích S3 cho ảnh và tệp tin.

Console: http://HOST:9001 Tài khoản: minioadmin/minioadmin http://HOST:9000/profile-pics/avatar.jpg

🧭 Internal DNS (Bind9)

Phân giải tên miền nội bộ cho các dịch vụ.

UDP 1053, zone cloud.local

📈 Monitoring (Prometheus)

Thu thập số liệu (metrics) từ các máy chủ trong hệ thống.

http://HOST:9090/targets

📊 Grafana

Trực quan hóa số liệu giám sát bằng dashboard.

http://HOST:3000 Tài khoản: admin/admin

⚖️ API Gateway / Load Balancer

Nginx reverse proxy, định tuyến API và cân bằng tải Round Robin.

http://HOST/ http://HOST/lb-test.html
